B

改成你自己的

Make it yours

每张卡片都是一个独立的 HTML 文件，不依赖任何框架。两条路线，按你的情况选。

Every card is one standalone HTML file with no framework. Pick a route.

路线 1：不装任何环境

Route 1: no setup

  1. 在画廊点开卡片 → 查看 HTML 源文件 → 右上角 Download raw file，或者直接下载整个仓库 zip
  2. 用记事本或 VS Code 打开，搜索要改的文字直接替换
  3. 改配色：按下面的色值表全局替换
  4. 双击文件用 Chrome 打开预览
  5. 导出高清图：按 F12 → 点手机图标 → 尺寸填 1080 × 1440、DPR 选 2 → 按 Ctrl/⌘ + Shift + P，输入 Capture screenshot 回车，得到 2160 × 2880 的图
  1. Open a card → View HTML source → Download raw file, or grab the repo zip
  2. Open it in any text editor and replace the text
  3. Recolour by replacing the values in the palette table
  4. Open the file in Chrome to preview
  5. Export: F12 → device toolbar → 1080 × 1440, DPR 2 → Ctrl/⌘ + Shift + P → Capture screenshot (2160 × 2880)

路线 2：一条命令批量导出

Route 2: batch export

需要 Node.js 18 以上。改完任意卡片后，一次导出全部图片：

Needs Node.js 18+. Edit any card, then export every image at once:

git clone https://github.com/tgchtggn29-bit/iphone-duo-design-kit.git
cd iphone-duo-design-kit
npm install
npx playwright install chromium
npm run render                # 全部 31 张
npm run render -- 17-sports   # 只导出一张

卡片底部换成你自己的署名：

Put your own credit line on every card:

node scripts/build-cards.cjs source/canvas github.com/你的用户名/你的仓库
npm run render

安装在线 Skill

Install the online skill

装进 Claude Code 等支持 Agent Skills 的工具后，它会自动在合适的时候按这套模式做适配和评审。

Once installed in Claude Code or another Agent Skills tool, it is used automatically when you adapt or review a screen.

SKILL.mdhttps://tgchtggn29-bit.github.io/iphone-duo-design-kit/skill/SKILL.md
D=~/.claude/skills/iphone-duo-layout-patterns
mkdir -p $D/references
curl -fsSL https://tgchtggn29-bit.github.io/iphone-duo-design-kit/skill/SKILL.md -o $D/SKILL.md
curl -fsSL https://tgchtggn29-bit.github.io/iphone-duo-design-kit/skill/references/patterns.md -o $D/references/patterns.md
npx skills add tgchtggn29-bit/iphone-duo-design-kit
git clone --depth 1 https://github.com/tgchtggn29-bit/iphone-duo-design-kit.git
cp -r iphone-duo-design-kit/skills/iphone-duo-layout-patterns ~/.claude/skills/

只想在一个项目里用：把路径里的 ~/.claude/skills 换成项目下的 .claude/skills。装好后可以直接说：“按 iPhone Duo 的模式检查这个页面”“把这个列表页改成 Duo 适配”。

For one project only, use .claude/skills inside the project. Then ask: "review this screen against the iPhone Duo patterns" or "adapt this list view for iPhone Duo".

数据接口

Data API

静态 JSON，GET 请求即可，免密钥、支持跨域，可以接进你自己的网站、插件或 AI 工作流。

Static JSON over GET. No key, CORS enabled. Use it in your own site, plugin or AI workflow.

接口Endpoint返回Returns
GET /api/index.json全部 31 项的目录：编号、中英标题、姿态、详情地址All 31 entries: id, titles, poses, detail URL
GET /api/patterns/{id}.json单个模式：说明、SwiftUI 提示、预览图、2x 原图、HTML 源文件地址One pattern: summary, SwiftUI hint, image and source URLs
GET /api/rules.json屏幕尺寸、尺寸类别和四条核心规则Device sizes, size classes and the core rules
GET /patterns.json全部数据一个文件Everything in one file
GET /llms.txt给大模型读的文字索引Plain-text index for LLMs
