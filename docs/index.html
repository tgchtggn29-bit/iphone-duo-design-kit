全部卡片

3:4 竖版，适合小红书、公众号和 X。点开可以下载 2160 × 2880 原图和 HTML 源文件。

怎么用

设计评审、发内容、给 AI 写代码，都可以直接拿去用。

直接发图

exports/png 里是全部 2x 原图，按编号排好，可以直接发小红书、公众号或 X。

改成你自己的

cards/ 下每张卡片都是独立 HTML，改文字和颜色后重新导出：

npm install
npm run render

给 AI 用

data/patterns.json 是结构化的模式库，skills/ 里有可安装的 Agent Skill，让 AI 按这些模式做适配。
